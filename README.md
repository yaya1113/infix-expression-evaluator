# 基于栈的中缀表达式求值

> 数据结构课程设计 —— 用栈结构完成中缀表达式的后缀转换与求值

## 项目简介

本项目实现一个控制台程序，可读取用户输入的中缀表达式（如 `3 + 4 * 2 - ( 6 / 3 )`），
先借助运算符优先级与栈结构将其转换为后缀表达式（逆波兰式），再对后缀表达式求值输出结果。

核心考察点在于**栈的典型应用**：字符栈负责括号匹配与运算符优先级判断，整数栈承载运算数，
两个栈协同完成整个转换与计算流程。

## 功能特性

- **表达式转换**：中缀 → 后缀，使用运算符栈 + 运算数栈的标准算法。
- **优先级处理**：通过 `getPriority` 函数区分 `+ -`（优先级 1）与 `* /`（优先级 2），`(` `)` 作为分隔符。
- **括号匹配**：字符栈在遇到 `)` 时弹栈匹配对应 `(`，不匹配则判定为非法输入。
- **多位数支持**：连续数字字符被完整读取为一个操作数，而非逐位拆分。
- **异常处理**：对除零、空栈、括号不匹配等非法输入给出明确提示并终止当前计算，避免程序崩溃。

## 技术要点

| 关键结构 | 作用 |
| --- | --- |
| `CharStack` | 字符栈，存储运算符与括号，用于优先级判断与括号匹配 |
| `IntStack` | 整数栈，存储运算数，在求值阶段参与运算 |

转换阶段只需字符栈，求值阶段只需整数栈，两个阶段分工明确。

## 编译与运行

源码为标准 C++，无第三方依赖，使用 g++ 编译：

```bash
g++ -std=c++11 -o infix src/main.cpp
./infix
```

或直接用 Visual Studio / Code::Blocks 打开 `src/main.cpp` 编译运行。

## 示例

```
输入：3 + 4 * 2 - ( 6 / 3 )
后缀表达式：3 4 2 * + 6 3 / -
计算结果：9
```
